# Super AI Agent Pro Station Max 2000

Studio IA personnel pour Windows, Mac et Linux : un Superviseur et une équipe d'agents qui travaillent sur tes projets, sur ton PC.

## Installer
**Windows**
1. Télécharge l'installateur : **[Installer-Studio.exe](https://github.com/marechalmelchior-cpu/super-ai-studio/raw/main/derniere/Installer-Studio.exe)**
2. Lance-le et suis le [guide](derniere/Guide%20d'installation.html).

**Mac et Linux** : dans un Terminal (Python 3.11 ou plus) :

```
curl -fsSL https://raw.githubusercontent.com/marechalmelchior-cpu/super-ai-studio/main/derniere/installer.sh | bash
```

## Mises à jour
Le studio vérifie ce dépôt une fois par jour (dossier `derniere/`) : les petites mises à jour s'installent seules,
les grosses attendent ton accord. Ce dépôt ne contient que le programme : aucune donnée personnelle.
