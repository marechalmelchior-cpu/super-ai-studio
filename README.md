# Super AI Agent Pro Station Max 2000

Studio IA personnel pour Windows : un Superviseur et une équipe d'agents qui travaillent sur tes projets, sur ton PC.

## Installer
1. Ouvre la dernière version : **Releases** (à droite).
2. Télécharge `Installer-Studio.exe` et lance-le.
3. Suis le guide fourni avec l'installateur.

Le studio se met à jour tout seul à partir des versions publiées ici. Ce dépôt ne contient que le programme : aucune donnée personnelle.
